# Calm futuristic motion

Motion is semantic, short and optional: instant 80–120ms, fast 140–180ms,
standard 180–240ms, deliberate 260–360ms and ambient 2.4–4s. It never delays a
click, approval or navigation and never uses a permanent pulse to imply work.

`createMotionPolicy(true)` is the reduced-motion equivalent: decorative
animation is disabled and state changes remain visible through layout, text,
focus and status—not color or motion alone.
